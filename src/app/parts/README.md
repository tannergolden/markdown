## 💡 What This Folder Is For

A run draws a page in parts. Each module here measures what its part needs,
through the ports the run hands it, then plans the files and the README blocks
the part makes. The drawing code itself lives in
[`../../domain/`](../../domain/README.md).

[`trophies/`](trophies/) measures a person or a repository for the trophy case,
and reads their commits for the heavy achievements, a hundred at a time, under a
budget.
