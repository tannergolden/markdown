## 💡 What This Folder Is For

A page that names no theme is drawn in standard
([ADR-0004](../../../docs/adrs/ADR-0004-Standard-As-The-Default-Theme.md)): the
original badges' own look, grown to the size of a header.
[`pieces.py`](pieces.py) draws a badge's own parts at every scale, and the
masthead banners ([`banners.py`](banners.py)) and the six elements
([`elements.py`](elements.py)) are built from them.
