## 💡 What This Folder Is For

The six blueprint elements a page's body is made of: the schematic, the
instruments, the milestones, the roster, the certificate and the placards
([`draw.py`](draw.py)), drawn on the same paper as the page's header and footer.
The games played on @tannergolden's profile are drawn there alone: Tic-Tac
([`tictac/`](tictac/README.md)), Pentago ([`pentago/`](pentago/README.md)),
Checkers ([`checkers/`](checkers/README.md)), and Chess with chess's own Hall of
Fame ([`chess/`](chess/README.md)), four boards drawn by one hand
([`games/`](games/README.md)), and the Hall of Fame of all four games
([`hall/`](hall/README.md)), with a replay of every game a person's own move
won ([`replay/`](replay/README.md)).
What each draws from is the `elements:` section of the page's settings
([`data.py`](data.py)).

[`layout.py`](layout.py) computes every position, so a data file never carries a
coordinate.
